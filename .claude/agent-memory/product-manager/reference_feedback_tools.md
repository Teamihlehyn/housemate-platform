- Tally (Tally BV, Ghent, Belgium) says it is EU-hosted. The free plan has hidden fields, conditional logic, Sheets/Notion/webhooks and unlimited submissions (fair use). Pro was $24/month on 2026-11-09 (the research kit said $29). Free-plan DPA not confirmed. Sources: tally.so/pricing, tally.so/privacy, tally.so/help/hidden-fields.
- Microsoft Clarity has enforced consentv2 for EEA/UK/CH visits since 2025-10-31 (learn.microsoft.com, Clarity Consent API v2).
- NEXT_PUBLIC_FEEDBACK_URL replaces the built-in feedback dialog rather than adding to it. Recommended split: built-in form for the pill, Tally for the waitlist and survey via a separate survey link. See [[project-beta-launch]].
